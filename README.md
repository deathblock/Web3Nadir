# Web3Nadir

Translates and compiles Solidity smart contracts into readable, human-friendly assembly code for Ethereum developers.

The key benefits of using Web3Nadir include:

- Translates and compiles Solidity smart
- contracts into readable, human-friendly assembly
- code for Ethereum developers

- Translates and compiles Solidity smart

- code for Ethereum developers

## Technology Stack

- rust
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Nadir.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Web3Nadir is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
